# Sunny Corner Café — Windows Forms Desktop Application

## 📌 Project Purpose
This desktop application is designed for **internal café staff management**.  
It provides CRUD operations for users, menu items, orders, and reservations.  
Admins can manage users and reset passwords, while customers can update their profiles and place orders.

---

## 🛠 Technology Stack
- C# WinForms (.NET 6/8)
- Microsoft SQL Server (LocalDB for development)
- Entity Framework for data access
- Git / GitHub for version control
